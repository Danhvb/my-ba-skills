# Business Analysis Directory Structure

This directory contains all business analysis artifacts, organized by the stage of the analysis lifecycle.

## Folder Structure

### 01-requests
Contains initial requests, problem statements, and raw input from stakeholders.
- Examples: Emails, ticket exports, initial briefs.

### 02-analysis
Contains detailed analysis, research, feasibility studies, and current state assessments.
- Examples: Gap analysis, competitive analysis, data analysis.

### 03-requirements
Contains formal requirement documents.
- **BRD** (Business Requirement Document)
- **SRS** (Software Requirements Specification)
- **FRS** (Functional Requirements Specification)
- **User Stories**

### 04-design
Contains system design specifications and models.
- Examples: API specifications, database schemas, sequence diagrams, UI mockups.

### 05-testing
Contains testing artifacts.
- Examples: Test plans, test cases, UAT scripts, bug reports.

### 06-planning
Contains project management and planning documents.
- Examples: Roadmaps, timelines, WBS, resource plans.

### 07-meeting-minutes
Contains notes from meetings with stakeholders and the team.

### output
Contains generated files, exports, and large datasets.
**Note:** This folder is git-ignored to prevent cluttering the repository.
