# Senior Business Analyst Skill Set

A comprehensive collection of modular skills for AI assistants to perform professional Business Analysis work according to industry standards.

## Overview

This skill set enables AI assistants to work as Senior Business Analysts across **Web, Mobile, ERP, CRM, CDP, and E-commerce** projects using **Hybrid methodologies** (Agile + Waterfall) with tools like **Lark, Notion, and Figma**.
